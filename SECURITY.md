# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest release on `main` | :white_check_mark: |
| Earlier versions | :x: |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately through the [GitHub security-advisory form](https://github.com/SharpSplinter/Naughty-Company-Companion/security/advisories/new).

Include a clear description, affected version, reproduction steps or proof of concept, expected impact, and any proposed mitigation. Never include live API keys, account credentials, session tokens, or private player data.

The maintainer will aim to acknowledge a valid report within 7 calendar days, assess it privately, and coordinate a fix and disclosure timeline with the reporter. Public disclosure should wait until a fix or mitigation is available unless there is an immediate, active risk to users.

## Scope

This policy covers the code and released userscript in this repository, including its local storage, API-key handling, TornPDA integrations, and export behavior. It does not cover vulnerabilities in Torn, TornStats, Tampermonkey, TornPDA, browsers, operating systems, or third-party services; please report those to their respective maintainers.

When testing, use only accounts and data you control, avoid disrupting Torn or TornStats services, and do not access other users' data.
